# Simulation screenshots

After running the project in Tinkercad Circuits or Arduino IDE, add screenshots here:
- `normal_status.png` — input between the example thresholds
- `undervoltage_warning.png` — input below the low example threshold
- `overvoltage_warning.png` — input above the high example threshold

Only add screenshots from a simulation you actually ran. Do not present mockups as real test evidence.
